# Strategy

This folder defines how the business competes.

Technology changes.

Markets change.

Services change.

The strategy should evolve slowly.

Every strategic decision should align with the company's philosophy:

> Simplify Complexity.

If an opportunity increases unnecessary complexity—for either the client or the business—it should be questioned.
