# Templates

Templates are reusable tools that support consistent, high-quality consulting delivery.

Templates should reduce unnecessary effort while preserving thoughtful analysis.

A template is not a replacement for judgment.

It provides structure so more time can be spent understanding problems and creating value.

---

## Principles

Templates should be:

- Simple
- Adaptable
- Client-focused
- Easy to maintain
- Improved through experience

---

## Usage

Templates should be customized for each engagement.

Do not force every client into the same process.

The framework provides consistency.

The consultant provides judgment.
