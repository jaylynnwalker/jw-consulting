# Documentation Standards

## Purpose

Create clear, reusable, professional documentation.

Documentation is a core consulting deliverable.

---

## Standards

Documents should be:

- Clear
- Concise
- Organized
- Easy to maintain
- Written for the intended audience

---

## Types of Documentation

Examples:

- Process maps
- Requirements documents
- Recommendations
- Implementation plans
- Training materials

---

## Principle

Good documentation reduces complexity.

Poor documentation transfers complexity to someone else.
